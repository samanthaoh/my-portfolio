# Portfolio

Personal portfolio website built with React, Vite, and Tailwind CSS v4.

## Stack

- React 19
- Vite 8
- Tailwind CSS v4

## Getting Started

```bash
npm install
npm run dev
```

## Structure

```
src/
├── App.tsx       # All sections and components
└── index.css     # Global styles, animations, fonts
```

## Sections

- **Hero** — glitch title, floating blobs, animated shapes
- **About** — setlist-style bio card
- **Projects** — ticket stub cards with hover tilt
- **Experience** — festival lineup timeline
- **Skills** — EQ bar visualizer
- **Contact** — backstage pass card
