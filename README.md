# Samantha Oh’s portfolio

Personal portfolio built with React, TypeScript, Vite, and plain CSS.

## Development

```sh
npm install
npm run dev
```

```sh
npm run build
npm run lint
```

The site is a single scrolling page: Home, About, Experience, Projects, Skills, and Fun.
Content lives in `src/data.ts`. `src/index.css` contains the shared styling.
The headshot, resume, project screenshot, and Rokiest font are in `public/`.
The name animation supports hover, tap, keyboard focus, and reduced-motion preferences.
